# H2 2/3% image-quality and RH20 A/B (2026-08-20)

## Question

Can the low-quality late frames in `H2_only_4` and `H2_only_5` be improved and
used as exact 2/3% supervision, or can the reviewed RH20 ramps safely replace
them?

## Visual and sharpness audit

The review atlas is generated by `make_h2_23_comparison_atlas.py`:

- `output/h2_23_rh20_comparison_v1/h2_23_rh20_comparison.jpg`
- `output/h2_23_rh20_comparison_v1/comparison.csv`

The atlas shows the raw crop beside a mild CLAHE/chroma-enhanced rendering. The
enhanced rendering is for human inspection only. It is not used as a model
input.

| Source | Frame | Laplacian sharpness | Decision |
|---|---:|---:|---|
| `H2_only_test` | 2% / 3% | 143 / 151 | verified training/reference |
| `H2_only_test_2` | 2% / 3% | 157 / 181 | verified training/reference |
| `H2_only_test_3` | 2% / 3% | 531 / 354 | verified training/reference |
| `H2_only_4` | 2% / late partial | 106 / 107 | late frame is partial 2--3%, not exact |
| `H2_only_5` | 2% / late partial | 119 / 47 | late frame is both blurred and partial |
| RH20 run 3 | reviewed 2 / 3 | 136 / 149 | weak cross-check only |
| RH20 run 4 | reviewed 2 / 3 | 171 / 377 | weak cross-check only |

Sharpening or upscaling the run-4/run-5 images cannot restore missing optical
information or turn a partial physical response into an exact concentration
label. Applying it only to training data would also create a preprocessing
domain mismatch with the phone app.

## Leakage-safe model tests

### Verified 2-vs-3 expert

A binary expert trained only from verified H2-only runs (`test`, `test_2`, and
`test_3`) obtained:

- exact accuracy: **.815**
- balanced accuracy: **.774**
- 2% recall: **.700**
- 3% recall: **.847**

### Adding reviewed RH20 2/3 candidates

Adding RH20 stage-2/stage-3 candidates as weak labels reduced performance:

- exact accuracy: **.740**
- balanced accuracy: **.690**
- 2% recall: **.600**
- 3% recall: **.780**

Therefore RH20 stage 2/3 is not admitted to the 2-vs-3 expert. The previously
approved RH20 0%, 1%, and 3% weak samples remain eligible for the global model;
this test changes only the 2/3 boundary expert.

### Global model plus confidence-gated expert

Nested leave-one-video-out gating preserved exact accuracy while improving the
ordered-concentration metrics:

| Metric | Corrected global | Global + expert |
|---|---:|---:|
| exact accuracy | .528 | .528 |
| balanced accuracy | .525 | **.545** |
| within one stage | .929 | **.944** |
| MAE (stage) | .565 | **.542** |
| 2% recall | .392 | **.568** |
| 3% recall | .316 | .243 |

This is useful experimental progress, but it is not deployed because the 3%
recall regression is too large and the exact accuracy is unchanged.

## Adopted policy

1. Keep run 4/run 5 late responses as low-weight partial 2--3% evidence, not
   exact 3% or 4% labels.
2. Do not train on enhanced images. Use enhancement only for visual review.
3. Do not add RH20 stage 2/3 to the boundary expert from the present review.
4. Keep the verified-only expert as the next candidate and tune its 3% gate
   before browser deployment.
5. The app's `Color view` switch changes only the displayed captured image;
   inference continues to read the original canvas pixels.

## 3%-recall-preserving asymmetric gate

`combine_h2_23_expert_constrained.py` tested separate 2-to-3 and 3-to-2
probability thresholds. A candidate was allowed only when its meta-training
results improved 2% recall while preserving 3% recall, exact accuracy, and MAE
relative to the corrected global model.

The honest nested leave-one-video-out result did **not** pass the aggregate
constraints. Its 2%/3% recalls and exact accuracy remained unchanged at
.392/.316/.528. Although within-one-stage accuracy improved to .944 and MAE to
.542, no 2% gain remained. One held-out fold (`h2-indoor-4`) had no feasible
gate when that run was excluded from threshold selection.

A diagnostic fixed gate (`3 -> 2` only above .95 expert probability; the
`2 -> 3` threshold was inactive) appears to pass when all cross-fitted labels
are used to select the threshold:

| Metric | Corrected global | Diagnostic fixed gate |
|---|---:|---:|
| exact accuracy | .528 | .533 |
| 2% recall | .392 | .432 |
| 3% recall | .316 | .316 |
| MAE | .564 | .537 |

This apparent 2% improvement consists of only three corrected frames, all from
`h2-indoor-4`. The other thirteen changed frames are test-3 0%/1% errors moved
from prediction 3 to prediction 2; they reduce MAE but do not become exact.
Consequently the fixed-gate score is a useful diagnostic but not independent
deployment evidence. The current browser concentration model remains unchanged.
