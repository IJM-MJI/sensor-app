# RH20 cropped H2 quantitation audit

## 데이터

다음 네 독립 crop run을 2 Hz로 다시 추출했다.

- `1_90_RH20_2_x2_cropped.mp4`
- `1_90_RH20_3_x2_cropped.mp4`
- `1_90_RH20_4_cropped.mp4` (normal speed)
- `1_90_RH20_cropped.mp4` (run 5 normal speed; x2에서 생략된 중간 프레임 포함)

기존 x2 추출은 총 944프레임이었다. run 5를 일반속도 대표본으로 바꾼 뒤에는 총
1,159프레임(기존보다 215개 증가)이며 불꽃이 위가 되도록 정렬했다. 실험 run 설명과 별개로 저장 파일 수준에서
`1_90_RH20_cropped.mp4`와 run 5 x2의 센서 중심 대응 프레임은 상관
0.99979--0.99989, 평균 픽셀 차이 0.64--0.93이었다. 다른 run 4와 비교하면 상관 0.23,
차이 약 67이다. 따라서 두 파일은 독립 검증 단위로 세지 않고 같은 source group으로 묶되,
학습 추출에는 더 많은 시점을 보존한 일반속도 원본을 대표 파일로 사용한다.

## 타임라인 없는 사전 매칭

기존 Reaction 시간을 숨기고 불꽃 변화의 자동 peak와 `H2_only_test_2` optical atlas만으로
분석했을 때 매칭된 최대값은 run 2/3/4/5에서 각각 3.95/3.25/2.75/1.0%였다. 944프레임
중 상호 최근접 고신뢰 학습 후보는 8개뿐이었고, run 2와 run 5의 자동 peak도 불안정했다.
따라서 이 결과만으로 exact 0--4% 라벨을 만들지 않는다.

사용자가 알려준 `Initial → Reaction → Recovery` 순서만 추가해 시작/끝 baseline과 가장
다른 연속 구간을 Reaction으로 자동 분할하는 v2도 시험했다. 검출 구간은 run 2/3/4/5에서
각각 62.0--71.5, 14.5--83.0, 103.5--121.0, 76.5--203.5초였고 고신뢰 후보는 총 3개에
그쳤다. recovery 지연과 프레임별 색 흔들림 때문에 phase 순서만으로 정확한 전체 Reaction
경계를 복원할 수 없었다. 따라서 기존에 제공된 Reaction 경계는 사용하되 내부 농도와
최대 농도는 약한 optical-equivalent 라벨로 유지하는 것이 현재 가장 안전하다.

## 기존에 알려진 RH20 Reaction을 사용한 A/B

이전에 제공된 Reaction 경계는 사용하되 내부 1/2/3%는 낮은 가중치의 ramp 순서로만
사용했다. 원본과 crop은 동시에 넣지 않고 완전히 교체했다. 검증은 기존 H2-only 다섯
run만 사용했다.

모든 crop 끝을 4%로 강제하면 H2 4% recall이 0%가 되어 실패했다. 실제 H2가 부족할 수
있다는 조건을 반영해 각 crop의 끝을 위 optical-equivalent 최대값으로 제한하고 endpoint도
약한 가중치로 바꾼 결과는 다음과 같다.

| 조건 | Exact | Stage-balanced | ±1단계 | MAE | H2 1–4 exact | H2 1–4 balanced |
|---|---:|---:|---:|---:|---:|---:|
| 기존 RH20 원본 weak ramp | 43.3% | 50.0% | 91.1% | 0.668%p | 38.7% | 37.9% |
| Crop + unforced optical max | 48.0% | 48.6% | 96.8% | 0.554%p | 48.5% | 50.2% |

run 5를 일반속도본으로 바꿔 215개 프레임을 더 넣은 추가 실험에서는 단순 동일 가중치의
held-out exact/balanced가 36.9%/41.5%로 하락했다. 일반속도본의 프레임 가중치를 절반으로
낮춰 run 5의 총 영향력을 보정해도 38.1%/43.9%였다. 즉, 추가 프레임 자체가 부족했던 것이
아니라 그 프레임들의 농도 상태를 확실히 구분하지 못한 것이 병목이다. 일반속도본은 향후
검토/라벨링 원본으로 보존하지만 현재 최선의 농도 모델에는 자동 약라벨 전체를 추가하지 않는다.

Reaction 내부에서는 불꽃 LAB/chroma의 시작--끝 변화축을 구하고, 9-frame 중앙값과 isotonic
regression으로 `Initial → Response` 단조 경로를 강제하는 optical-path 라벨도 시험했다.
가중치 0.25는 exact 36.8%, 0.10은 46.1%였다. 가중치 0.05에서는 exact가 49.4%로 기존
48.0%보다 1.4%p 높았지만 balanced 48.2%(기존 48.6%), ±1단계 93.4%(96.8%), MAE
0.579%p(0.554%p)로 세 지표가 악화됐다. 두 후보의 예측쌍을 다른 영상에서만 학습한
leave-one-video-out lookup 앙상블도 공통 687프레임에서 exact 48.0%, ±1단계 89.2%,
MAE 0.655%p로 실패했다. 따라서 optical-path는 연구 후보로만 보존하고 배포하지 않는다.

## 사용자 확인 Reaction/Recovery 경계

| 영상 | Reaction | Recovery |
|---|---:|---:|
| `1_90_RH20_5_x2_cropped.mp4` | 0--54 s | 54--107 s |
| `1_90_RH20_4_cropped.mp4` | 0--120 s | 120--180 s |
| `1_90_RH20_2_x2_cropped.mp4` | 10--60 s | 60--85 s |
| `1_90_RH20_3_x2_cropped.mp4` | 0--60 s | 60--97 s |
| `1_90_RH20_cropped.mp4` | 0--90 s | 90--214 s |

이 경계를 적용해 run 5 normal/x2를 별도 A/B했다. Reaction 시간에 선형 비례한 약라벨은
x2/normal exact가 33.2%/40.4%로 실패했다. 같은 경계 안에서 optical path와 0.05 가중치를
사용하면 x2는 43.1%, normal은 49.1%였다. normal 후보의 balanced 48.6%, ±1단계
93.4%, MAE 0.582%p는 기존 최선의 48.6%, 96.8%, 0.554%p보다 전반적으로 낫지 않다.
Recovery 마지막 5초만 완전 회복 0% anchor로 추가한 조건도 exact 45.3%로 하락했다.
따라서 확인된 경계는 phase 분리에는 채택하되 기존 배포 모델은 유지한다.

`make_rh20_boundary_review.py`는 각 run의 시간 비례 경계와 optical-path 경계를
`H2_only_test_2`의 인접 단계 기준 프레임 사이에 배치한다. 총 12개 경계이며 검토자는 각
행에서 가운데 `TIME`/`OPTICAL` 중 더 타당한 후보 또는 `둘 다 아님`만 선택하면 된다.

사용자 검토 결과 run 3은 6.5/7.5/28.5초, run 4는 22/65.5/109초, run 5 x2/normal은
22.5/47초의 단계 midpoint를 채택했다. run 2는 0→1에 16.5초, 1→2에 10초가 선택되어
시간 순서가 역전됐고 사용자도 환경상 구별이 어렵다고 평가했으므로 농도 학습에서 제외한다.

검토 라벨 가중치 0.02가 가장 좋았다. run 5 normal 대표본은 exact 51.1%, balanced
52.5%, ±1단계 94.3%, MAE 0.547%p였고 단계 recall은 0/1/2/3/4%에서 각각
48.7/50.0/72.3/50.5/40.8%였다. x2 대표본은 50.7/52.7/94.1%/0.554%p로 normal보다
exact와 MAE가 낮았다. 기존 cropped 최선 대비 normal 후보는 exact, balanced, MAE가
개선됐지만 ±1단계가 96.8%에서 94.3%로 하락했다. 기존/신규 예측의 leave-one-video-out
앙상블과 2단계 이상 불일치 시 기존값을 쓰는 safety rule도 네 지표를 동시에 개선하지 못했다.
따라서 사용자 판정은 유효한 개선 신호로 보존하지만 아직 앱에는 배포하지 않는다.

사용자의 품질 평가를 반영해 run 3 가중치를 run 4/5의 절반으로 낮춘 profile도 시험했다.
기본 가중치 0.02에서는 반올림 예측이 동일했고, 0.04에서는 balanced가 52.9%로 소폭
상승했지만 exact 49.7%, ±1단계 94.1%, MAE 0.564%p로 악화됐다. 따라서 단순한
환경별 가중치보다 동일 0.02 가중치가 현재 최선이다.

## 0/1/3% 선택적 학습

사용자 검토 데이터에서 0/1/3%만 남기고 2/4%는 기존 데이터만 사용했다. 가중치 0.01의
단일 모델은 exact 52.1%, balanced 52.8%, ±1단계 94.8%, MAE 0.532%p였다. 기존보다
exact/balanced/MAE는 개선됐지만 하나의 회귀 경계가 함께 이동해 ±1단계가 낮았다.

따라서 기존 모델과 선택 모델이 2/4% 부근에서 다를 때 기존 신뢰도를 사용하는 보수 규칙을
추가했다. 규칙과 신뢰도 threshold는 매 held-out 영상의 정답을 보지 않고 나머지 네 영상에서만
선택했다. 이 `selective_confidence` LOVO 결과는 다음과 같다.

| 조건 | Exact | Balanced | ±1단계 | MAE |
|---|---:|---:|---:|---:|
| 기존 cropped 최선 | 48.0% | 48.6% | 96.8% | 0.554%p |
| 0/1/3 선택적 단일 모델 | 52.1% | 52.8% | 94.8% | 0.532%p |
| 선택적 confidence hybrid | **51.9%** | **54.9%** | **97.4%** | **0.508%p** |

hybrid의 0/1/2/3/4% recall은 51.3/54.3/74.8/42.2/51.6%다. 기존
42.1/38.0/75.5/41.7/45.8%와 비교하면 2%는 0.7%p 차이로 거의 유지되고 나머지
단계는 모두 개선된다. 두 모델과 confidence rule을 브라우저에 함께 내보내는 작업 전까지는
검증 후보이며 현재 앱 파일을 자동 교체하지 않는다.

| H2 단계 | 기존 recall | Crop optical recall |
|---:|---:|---:|
| 0% | 98.7% | 42.1% |
| 1% | 21.7% | 38.0% |
| 2% | 49.1% | 75.5% |
| 3% | 30.1% | 41.7% |
| 4% | 50.5% | 45.8% |

Crop optical 후보는 반응 단계 1--4%의 exact/balanced와 전체 exact, ±1단계, MAE를
크게 개선하지만 0% 경계를 악화시킨다. 앱은 상태 모델이 Initial이면 H2 0%로 고정하므로
이 후보는 **H2-response 전용 농도 모델**로 유망하다. 그러나 실제 상태 게이트와 결합한
end-to-end 검증 전에는 배포하지 않는다. 원본 0% anchor를 단순 추가한 hybrid는 exact
38.1%, balanced 46.8%로 악화되어 채택하지 않았다.

## 다음 단계

현재 앱의 4상태 held-out 예측을 concentration 예측 앞에 실제로 적용한다. Initial은 0%로
고정하고 H2-only/simultaneous로 판정된 프레임에만 crop optical 농도 모델을 통과시킨다.
end-to-end H2 0--4% confusion matrix와 coverage가 기존 앱보다 좋아질 때만 모델을 내보낸다.
